INFOAutentikasi & Aturan Umum

Semua endpoint mewajibkan parameter query auth yang cocok dengan auth key server. Nilai dan cara penyimpanan auth key ini bisa berbeda-beda tergantung konfigurasi masing-masing server. Tanpa parameter ini, server membalas 401 Unauthorized.

Aturan validasi umum

AturanKeterangan
UsernameHanya huruf & angka (regex ^[a-zA-Z0-9]+$), tidak boleh duplikat.
Angka (quota / exp / limitip)Harus numerik murni, dikirim sebagai string digit.
KuotaDalam satuan GB, dikonversi otomatis ke byte di server.

Format respons

Semua respons berbentuk JSON dengan pola {"status":"success"|"failed", "data"|"message": ...}.

Dibuat untuk didokumentasikan secara statis (GitHub Pages). Ganti nilai contoh (auth, domain, IP, dsb.) sesuai konfigurasi server kamu sendiri.
